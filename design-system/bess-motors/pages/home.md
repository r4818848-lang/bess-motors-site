# Homepage

Overrides for `design-system/bess-motors/MASTER.md`.

- The first screen is one shared studio. It does not become a row of car cards.
- Copy, prices, language strings, and the booking, phone, directions, and VIN actions stay as they are.
- The eyebrow uses `text-bm-ink`. Primary and outline actions use the shared button classes.
- Service tiles use `.bm-service-card`. Hover does not translate the card.
