# Рабочий календарь iPhone

Создай отдельный календарь iCloud с названием **BESS MOTORS**. В Production проекта Vercel **bess-motors-site** задай BESS_ICLOUD_USER и BESS_ICLOUD_APP_PASSWORD (пароль приложения Apple). После изменения переменных активируй новую сборку. BESS_ICLOUD_MECHANIC_ID задаёт механика по умолчанию.

Кнопка ↻ iCloud запускает обмен вручную. Автоматический обмен использует существующий пятиминутный вызов Vercel. Для нового визита на iPhone укажи работу в заголовке и добавь в заметки:

    NAME: Имя клиента
    TEL: +48XXXXXXXXX
    MECH: идентификатор механика в ERP

MECH можно опустить при заданном механике по умолчанию или при одном механике в ERP. Для переноса измени время события, для отмены удали связанное событие. Поддерживаются отдельные события с длительностью, кратной 15 минутам. При конфликте приведи дату, время, длительность и заголовок к согласованным значениям в обеих версиях.
