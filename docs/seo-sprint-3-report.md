## Search Console

Импорт: `npm run seo:gsc -- --current data/gsc/current --previous data/gsc/previous --out data/gsc/baseline.json`.

Из Performance → Export положить `Queries.csv`, `Pages.csv`, `Countries.csv`, `Devices.csv`, `Dates.csv`. Папка `data/gsc/` в gitignore. Скрипт пишет baseline только если в текущем периоде есть хотя бы одна строка. Пустой каталог даёт `current: null`, а не нули.

Правила разбора, это не метрики сайта:

- низкий CTR: коммерческое слово (шины, масло, тормоза, диагностика, механик и соседние услуги), показы ≥ 20, CTR < 3%;
- близко к первой странице: позиция 8–20;
- сравнение периодов считается только когда есть итог кликов и показов в обоих CSV.

Подтверждённого спроса из Search Console сейчас нет. Все темы ниже — гипотезы, кроме уже существующих URL.
