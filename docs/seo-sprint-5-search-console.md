# Search Console — sprint 5

Импорт остаётся прежним: `npm run seo:gsc` и `src/lib/gsc-import.ts`. Второй загрузчик не добавлялся. Поверх него работает `src/lib/gsc-analysis.ts`.

## API

Вызова Search Console API нет. `describeSearchConsoleAccess()` по-прежнему возвращает `unavailable`, даже если в окружении есть имя переменной. Секрет в отчёт не попадает. Пока владелец не даст доступ сервисного аккаунта к свойству `https://www.bess-motors.com/`, статус API: UNAVAILABLE.

Рабочий путь: экспорт CSV из интерфейса Search Console. Файл кладётся в `data/gsc/` или передаётся в `POST /api/internal/seo/gsc` авторизованным admin. Каталог `data/gsc/` и `data/seo-private/` в gitignore. В репозиторий сырые выгрузки не коммитятся.

На 11 ноября 2026 реальной выгрузки нет. Показатели панели: NO_DATA, не нули.

## Что проверяет импорт

Колонки: дата или измерение (query, page, country, device), clicks, impressions, ctr, position. Пустой файл — `NO_DATA`. Файл без этих колонок — `INVALID`. Строка с пустым числом пропускается и считается неполной, а не нулём.

Окна 7, 28 и 90 дней узнаются по числу уникальных дат. Сравнение включается только если у двух периодов одинаковое число дней. Если набор месяцев разный, сравнение не подгоняется: в ответе есть пометка `different_months`. Это и есть учёт сезонности без выдуманной поправки.

Запросы делятся на брендовые (`bess`, `bess motors`, `bessmotors`) и остальные. Услуги: шины, масло, диагностика, тормоза, прочий ремонт. «Warszawa» в небрендовом сервисном запросе помечается как коммерческий запрос Варшавы. Районы P1, P2 и P3 ищутся как слова в тексте запроса. Это не место человека.

Анонимные строки `(other)` отбрасываются из группировки. Лимиты интерфейса Google, задержка данных примерно на два дня и неполные последние дни записаны в `GSC_LIMITATIONS`.

Страницы с низким CTR и запросы у первой страницы по-прежнему считает `flagQueries()`: коммерческий запрос, не меньше 20 показов, CTR ниже 3%, позиция 8–20. Без файла список пуст.
