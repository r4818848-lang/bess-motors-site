## Риски

- Карточка Google и часть каталогов не прочитаны официальным API. Чеклист нельзя считать уже внесённым в карточку.
- Сниппеты поиска могут ещё показывать старые часы «пн–сб 8:00–18:00», хотя текущий HTML production их не содержит.
- Кейсы на Vercel не сохраняются, пока нет отдельного хранилища. Публиковать нечего: очередь пустая.
- Распознавание лиц на фото нет. Владелец сам кадрирует снимок. Код снимает EXIF и режет явные идентификаторы в тексте.
- Панель не рисует график при NO_DATA. Рекомендации подписаны отдельно от измерений и ничего не публикуют.

## План публикации, без выполнения

1. Владелец сверяет карточку Google и DobryMechanik.
2. При желании копирует польский черновик в официальный интерфейс Google. Приложение его не отправляет.
3. Реальный ремонт заводится как draft, проходит review и approved, затем published. До этого страница не индексируется.
4. CSV Search Console кладётся в закрытый каталог. Панель покажет цифры из файла, не из выдуманного ряда.
5. Merge в main и выкладка — только отдельным разрешением.
